# DigitalAnalytics
Учебный проект по дисциплине "Цифровая аналитика"

Разработка приложения для изучения английского языка по методу флеш-карточек
Приложение предназначено для изучения и повторения английских слов методом флэш-карточек, а также для отслеживания пользователем своего прогресса. Приложение будет полезно для студентов, которые изучают английский язык в университете, преподавателей, которые могут составлять тесты и модули для студентов, а также любым людям, которые хотят самостоятельно изучать язык.
Приложение должно отвечать следующим требованиям:
Пользователь должен иметь возможность выполнять следующие действия:
1. Создавать различные модули (колоды) с названиями и описаниями, состоящие из карточек, имеющие следующие поля: слово, перевод, пример, транскрипция.
2. Редактировать колоду: изменять название и описание, а также удалять ее.
3. Отображать колоду с прогрессом (процент изученных карточек).
4. Осуществлять глобальный поиск по названиям колод, а также поиск по словам и переводам внутри карточек.
5. Фильтровать карточки по статусу (неизученные, изученные, для повторения).
6. Удалять модуль.
7. Отображение прогресса изученных слов за определенный период времени.
8. Отображение достижение (количество дней без перерывов в повторении, количество изученных карточек за этот период, количество изученных карточек за все время)
9. Режим тестирование: множественный выбор из 4 вариантов ответа, варианты ответа берутся из карточек этого же модуля.
10. Отображение статистики: количество карточек из всех модулей, изученные карточки, процент изученных карточек от общего количества; ежедневная статистика: карточки изученные за текущий день, процент правильных ответов, время, затраченное на изучение.
11. Карточки считаются изученными, если был пройден тест по данному модулю.

Приблизительное описание интерфейса:                                                                                                 В нижней части экрана расположено навигационное меню с четырьмя основными пунктами: главный экран, прогресс, поиск, настройки. 

На главном экране отображается общий прогресс и реализуется управление колодами. На верхней панели располагаетcя заголовок “мои колоды” кнопка добавить, при нажатии на которую открывается форма создания новой колоды. Ниже располагается блок со статистикой: количество карточек, сколько изучено. Список модулей отображается в виде карточек, каждый элемент списка содержит название модуля, краткое описание, процент изученных карточек, и также иконка для контекстного меню (то есть редактировать, удалить). 

По нажатию на колоду отображается новый экран. На верхней панели отображается название колоды и кнопки действий (тест, редактировать, удалить). Ниже располагается область с фильтрами для карточек, то есть отобразить все карточки, только изученные, неизученные.  
Карточки отображаются в виде вертикального списка, каждая карточка показывает слово, перевод, индикатор (изучено слово/не изучено). 

В правом нижнем углу отображается кнопка “добавить” для создания новой карточки в текущей колоде. 
Режим тестирования открывается как отдельный экран. На верхней панели отображается прогрессс теста и кнопка для выхода из теста. В основной области отображается слово на английском, ниже располагается область с четырьмя кнопками вариантов ответа. Правильный ответ подсвечивается зеленым, неправильный  — красным. Ниже ответов отображается кнопка “далее”. 

По нажатию на кнопку прогресс открываетя отдельный экран: на верхней панели отображается заголовок. Ниже отображается блок  достижениями: текущая серия (количество дней непрерывного изучения), количество изученных слов за текущий день, всего изученных слов. Ниже отображается общая статистика: всего карточек, изучено, осталось изучить, — и статистика за ткущий день: количество изученных карточек, правильных ответов. 

По нажатию на кнопку поиск открывается экран для глобального поиска: на верхней панели отображается строка поиска. Ниже отображаются результаты. 
На экране “настройки” располагается раздел “настройка приложения”:  ниже можно выбрать тему оформления. После данного раздела отображается раздел “управление данным”, далее находятся кнопки “экспортировать данные” и "импортировать данные".
