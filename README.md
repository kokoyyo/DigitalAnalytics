# DigitalAnalytics
Учебный проект по дисциплине "Цифровая аналитика"

Разработка приложения для изучения английского языка по методу флеш-карточек
Приложение предназначено для изучения и повторения английских слов методом флэш-карточек, а также для отслеживания пользователем своего прогресса. Приложение будет полезно для студентов, которые изучают английский язык в университете, преподавателей, которые могут составлять тесты и модули для студентов, а также любым людям, которые хотят самостоятельно изучать язык.
Приложение должно отвечать следующим требованиям:
Пользователь должен иметь возможность выполнять следующие действия:
1. Создавать различные модули (колоды) с названиями и описаниями, состоящие из карточек, имеющие следующие поля: слово, перевод, пример, транскрипция.
2. Редактировать колоду: изменять название и описание, а также удалять ее.
3. Отображать колоду с прогрессом (процент изученных карточек).
4. Осуществлять глобальный поиск по названиям колод, а также поиск по словам и переводам внутри карточек.
5. Фильтровать карточки по статусу (неизученные, изученные, для повторения).
6. Удалять модуль.
7. Отображение прогресса изученных слов за определенный период времени.
8. Отображение достижение (количество дней без перерывов в повторении, количество изученных карточек за этот период, количество изученных карточек за все время)
9. Режим тестирование: множественный выбор из 4 вариантов ответа, варианты ответа берутся из карточек этого же модуля.
10. Отображение статистики: количество карточек из всех модулей, изученные карточки, процент изученных карточек от общего количества; ежедневная статистика: карточки изученные за текущий день, процент правильных ответов, время, затраченное на изучение.
11. Карточки считаются изученными, если был пройден тест по данному модулю.
