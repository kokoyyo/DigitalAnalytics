История разработки Flashcard English (продолжение)
Дата: 2026-05-27
Q1: При первом поиске карточки выводятся не по размеру экрану, потом если чуть растянуть экран карточки становятся такими какими надо. Сделай так чтобы карточки были по размеру экрана

A1: Проблема решена путем получения ширины корневого окна перед созданием карточек. Добавлено принудительное обновление геометрии и передача wrap_width в методы отображения. Карточки теперь создаются сразу с правильной шириной.

Q2: Создай какие-нибудь два файла в формате json и csv для загрузки

A2: Созданы примеры файлов:

sample_data.json - с колодами "Английский A1", "Неправильные глаголы", "Путешествия"

sample_data.csv - табличный формат с теми же данными

sample_data_small.csv - для быстрого теста

sample_data_advanced.json - с дополнительными колодами "Business English" и "IT термины"

Q3: Как в этом приложении работает экспорт?

A3: Описан механизм экспорта в JSON и CSV. Экспорт находится в настройках → "Управление данными". JSON экспортирует полную структуру, CSV - табличный формат с заголовками. Данные сохраняются с кодировкой UTF-8.

Q4: Почему время отображается на 1 секунду больше чем должно быть?

A4: Исправлен метод format_time - используется int(round(minutes * 60)) для точного перевода минут в секунды. Убраны погрешности округления.

Q5: Время тестирования - 32 секунды. В прогресс было 7 мин 12 сек стало 7 мин 42 сек

A5: Исправлен метод update_daily_stats - время теперь правильно накапливается. Рекомендовано хранить время в секундах для большей точности. Добавлена проверка существующей записи перед обновлением.

Q6: Теперь неправильно отображается число изученных карточек

A6: Исправлен метод update_daily_stats - убрано автоматическое увеличение cards_studied. Добавлен отдельный метод increment_studied_cards() и get_today_studied_cards(). Теперь количество изученных карточек считается напрямую из таблицы cards по дате last_reviewed_at.

Q7: Собери оставшиеся запросы в один файл

A7: Создан файл HISTORY_ADDITIONAL.md со всеми оставшимися вопросами и ответами.
